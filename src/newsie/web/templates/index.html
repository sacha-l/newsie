Newsie

An event desk for German and Berlin political news. Compare reports of the same event, then approve what is published.

Newsie groups articles that describe the same occurrence, then separates what is known, what is only claimed, where accounts differ, and what is still unclear. It counts independent origins once when several outlets repeat the same report. A sentence stays in the edition only when a quoted passage supports it. Nothing is published until you approve it.
